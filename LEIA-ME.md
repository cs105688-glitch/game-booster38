# Calculadora (código aberto, licença MIT)
Calculadora simples. Sem anúncios, sem rastreadores, sem permissões (nem internet).
O código está em `app/src/main/assets/index.html` (interface e contas) e `MainActivity.kt` (só abre a tela).
Para gerar o APK sem PC: suba este zip no GitHub e use o workflow em `.github/workflows/build.yml`.
